🏗️ CPMS App - คู่มือศัพท์เทคนิค

วิธีการสั่งงานและชื่อเรียกส่วนต่างๆของแอปลิเคชัน

วันที่อัปเดต: 17 เมษายน 2566

📌 ส่วนประกอบ UI (Components)

ชื่อเรียก ตัวอย่าง อธิบาย
Card
(กล่อง)		 กล่อง "ค่าใช้จ่ายจริง ฿150,000" ชิ้นสี่เหลี่ยมที่บรรจุข้อมูล หรือสรุปผล
Input Field
(ช่องกรอก)		 ช่องกรอกจำนวนวัน, เงิน ช่องสำหรับพิมพ์ตัวเลขหรือข้อความ
Button
(ปุ่ม)		 ปุ่ม "บันทึก", "สร้าง", "✓" ปุ่มเพื่อทำการกระทำ (บันทึก, ยกเลิก, ลบ)
Table
(ตาราง)		 ตาราง Payments, Team, BOQ แสดงข้อมูลเป็นแถวและคอลัมน์
Tab
(แท็บ)		 📋 BOQ | 📅 Gantt | 🏠 ข้อมูล ปุ่มสลับเนื้อหา (ตั้งอยู่ด้านบน)
Modal / Dialog
(ป๊อปอัป)		 ป๊อปอัป "สร้างบ้านใหม่" หน้าต่างที่ปรากฏขึ้นมา เพื่อกรอกข้อมูลหรือยืนยัน
Dropdown / Select
(เลือก)		 เลือกโครงการ, เลือก Role ช่องสำหรับเลือกจากรายการ
Progress Bar
(แถบความคืบหน้า)		 เส้นแสดง 65% สีน้ำเงิน เส้นความสำเร็จหรือความคืบหน้า
Sidebar
(เมนูข้าง)		 📈 Timeline, ⊞ Dashboard เมนูแนวตั้งด้านซ้าย สำหรับเปลี่ยนหน้า
Notification
(การแจ้งเตือน)		 ข้อความเติม "สำเร็จ" สีเขียว ข้อความแจ้งเตือน (ข้อมูล, สำเร็จ, เตือน, ข้อผิดพลาด)

💰 ชื่อเรียกข้อมูล (Data Terms)

ชื่อ ตัวอักษรย่อ ความหมาย
BOQ - งบประมาณแผน (Bill of Quantities)
Actual - ค่าใช้จ่ายจริง (เงินที่จ่ายออกจริงแล้ว)
Variance Δ ส่วนต่าง = BOQ - Actual
Percentage / % % ความคืบหน้า (ความสำเร็จ)
KPI - ตัวชี้วัดหลัก (5 กล่องด้านบน Dashboard)

🗺️ หมวด / หน้า (Pages)

ไอคอน ชื่อหมวด งานหลัก
⊞ Dashboard ภาพรวมโครงการและบ้าน
💹 Finance วิเคราะห์การเงิน cost breakdown
📊 Analytics รายงานและวิเคราะห์ข้อมูล
📈 Timeline ดูความคืบหน้าของบ้านทั้งหมด
💰 Payments จัดการชำระเงิน
👥 Team จัดการสมาชิกทีม
📢 Marketing ติดตามลูกค้า
⚙️ Settings ตั้งค่าระบบ

📧 วิธีการสั่งงานที่ถูกต้อง

🎯 หลักการพื้นฐาน (5 ขั้นตอน)

1
บอกหมวด → "ในหมวด Finance..."
2
บอกส่วนประกอบ → "ใน Card..."
3
บอกตำแหน่ง → "ซ้ายสุด / ด้านบน / แถวที่ 2"
4
บอกสิ่งที่ต้องการ → "เปลี่ยนสี / เพิ่ม / ลบ / แก้"
5
บอกรายละเอียด → "จากสีเหลืองเป็นเขียว"

✅ ตัวอย่างคำขอที่ชัดเจน

ตัวอย่างที่ 1

ในหมวด Finance, Card ที่แสดง 'ค่าใช้จ่ายจริง' (ซ้ายสุด), อยากให้เปลี่ยนสีพื้นหลังจากเหลืองเป็นสีเขียว

ตัวอย่างที่ 2

ในแท็บ Gantt, เส้นแถบเวลาด้านบน, อยากให้เปลี่ยนชื่อเดือนจากภาษาอังกฤษเป็นไทยเต็ม

ตัวอย่างที่ 3

ในหมวด Dashboard, ตารางบ้าน (ด้านล่าง), อยากให้เพิ่มคอลัมน์แสดง 'วันเริ่มก่อสร้าง'

❌ ตัวอย่างคำขอที่ไม่ชัดเจน

ตัวอย่างที่ 1

"อยากให้แก้สีกล่องนั่น" → ไม่เข้าใจว่ากล่องไหน

ตัวอย่างที่ 2

"เพิ่มปุ่มหน่อย" → ไม่รู้ว่าเพิ่มปุ่มตรงไหน

ตัวอย่างที่ 3

"เปลี่ยนแถบนั่น" → ไม่ชัดว่าแถบใหน

📋 ตัวอย่างการสั่งงานจริง

1️⃣ "ในแท็บ Gantt, เส้นแดงแสดงวันนี้, อยากให้เปลี่ยนเป็นเส้นประ"
2️⃣ "ในหมวด Dashboard, Dropdownเลือกโครงการ (ด้านบน), อยากให้เพิ่ม option 'ทั้งหมด'"
3️⃣ "ในโหมด Mobile 📱, Sidebarควรเป็น Hamburger menu (☰) เล็กๆ"
4️⃣ "ปุ่ม 'บันทึก' (เขียว), อยากให้เปลี่ยนข้อความเป็น '✓ ยืนยัน'"
5️⃣ "ในหมวด Payments, Notificationด้านบน, อยากให้เปลี่ยนสีจากแดงเป็นสีส้ม"

📚 คำศัพท์เสริม

🎨 การออกแบบ (Design Terms)

คำศัพท์ ความหมาย ตัวอย่าง
Color (สี) สีของส่วนประกอบ เขียว, แดง, น้ำเงิน, ม่วง
Background (พื้นหลัง) สีพื้นหลังของกล่อง "สีพื้นหลังสีเขียว"
Size (ขนาด) ขนาดของส่วนประกอบ ใหญ่, เล็ก, ปกติ
Font (ฟอนต์) ลักษณะตัวอักษร ตัวหนา (Bold), ตัวเอียง (Italic)
Icon (ไอคอน) รูปสัญลักษณ์เล็กๆ 💾 บันทึก, ✓ ตรวจสอบ, ❌ ลบ

🛠️ การแก้ไข (Action Terms)

คำศัพท์ ความหมาย
เปลี่ยน (Change) เปลี่ยนแปลงสิ่งของที่มีอยู่
เพิ่ม (Add) เพิ่มสิ่งใหม่
ลบ (Remove) ลบสิ่งที่มีอยู่
ซ่อน (Hide) ไม่แสดง แต่ยังเก็บไว้
ย้าย (Move) ย้ายสิ่งของไปยังตำแหน่งอื่น
💡 เคล็ดลับ: ยิ่งคำขอชัดเจนเท่าไร การทำงานก็จะเร็วขึ้นเท่านั้น! ลองเขียนลงกระดาษก่อนส่ง เพื่อให้แน่ใจว่าชัดเจน
